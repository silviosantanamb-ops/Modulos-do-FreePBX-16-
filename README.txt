Painel de Mensagens - FreePBX 16
Versão 1.0.5

Interface renovada do módulo SIP Internal Messages, apresentado no menu como
"Painel de Mensagens". Mantém o encaminhamento nativo PJSIP MESSAGE e a
integração das notificações não lidas com o Painel do Operador.

Instalação: carregar o módulo sipmessages pelo Module Admin do FreePBX e
aplicar as alterações de configuração. Faça uma cópia de segurança antes de
actualizar uma instalação existente.
